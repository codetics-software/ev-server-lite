Open-source EV charging supervision for OCPP 1.6 and 2.0.1

EV Supervision Lite is a self-hosted charging station management system (CSMS). It includes a Kotlin OCPP server, a web dashboard, white-label iOS and Android driver apps, and public charging paid by QR code. Operators, installers and local authorities run it under their own brand, and pay no commission on charging sessions.

What it covers

OCPP 1.6 and OCPP 2.0.1

OCPP-J server with automatic version negotiation, persisted command queue, device model, smart charging profiles, firmware, logs, reservations and security profiles 0 to 3.

Multi-tenant workspaces

Each customer gets its own stations, users, RFID badges, tariffs, vehicles and Stripe account, isolated by the server.

White-label mobile apps

Native iOS and Android apps with CarPlay and Android Auto, QR code scanning, reservations and live session tracking, published under your own developer accounts.

QR code payment

Drivers scan, pay with Stripe Checkout and charge without an account. The final amount is computed from meter values and the balance is refunded.

Roaming and Plug & Charge

OCPI 2.1.1 roaming with partner badges, sessions and CDRs, plus ISO 15118 certificate management for Plug & Charge on OCPP 2.0.1 stations.

Tested in the open

Every commit runs the server, dashboard, Android and iOS test suites. Results and code coverage are published here.

Built for operators

  • Station detail with live connector status, OCPP event log and remote commands.
  • Tariffs by workspace, site, area, station or connector, with energy, time, parking and flat fees.
  • Driver billing, charging card sales, statistics, notifications and CSV exports.
  • PostgreSQL or MongoDB, Docker Compose or Kubernetes, on any cloud or on your own server.

Deploy it

Requirements: Java 25 and Node.js 24. Start the server and the dashboard locally:

cd ev-server && SPRING_PROFILES_ACTIVE=local ./mvnw spring-boot:run
cd ev-dashboard && npm ci && npm run dev

Production guides cover Docker Compose, Kubernetes, Google Cloud, AWS, Azure, Scaleway and Oracle Cloud: see the deployment guide and the architecture.
