Ces captures proviennent de l’application réelle, avec des données locales de démonstration dans H2. Les comptes des quatre rôles passent par la connexion normale. Les formulaires utilisent les contrôleurs Spring et les dépôts JPA. Les échanges OCPP des sessions sont créés par le service de protocole.

Le paiement utilise un adaptateur Stripe réservé aux tests, avec une confirmation simulée. La capture du suivi indique une demande de démarrage.
